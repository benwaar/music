# Chunk Schema

Every chunk in `knowledge/chunks/` is a markdown file with YAML frontmatter.

## Required frontmatter

```yaml
---
topic: "LD A, n"              # short title for the concept
category: z80-instruction     # one of the categories below
source_url: "https://..."     # where this was fetched from (see provenance below)
licence: "public-domain"      # licence or status of the source
tags: [load, 8-bit, immediate] # searchable tags
---
```

## Provenance (source_url values)

- **URL** — fetched from that URL by a fetch script. Verifiable.
- `"curated"` — hand-written by a human. Not fetched, but authored with domain knowledge.
- `"llm-curated"` — generated by an LLM. May be accurate but not grounded in a specific source. Treat with lower confidence than fetched or human-curated content.

## Categories

- `z80-instruction` — individual Z80 opcodes and addressing modes
- `z80-pattern` — common Z80 code patterns (scroll, multiply, etc.)
- `z80-undocumented` — undocumented Z80 opcodes (Sean Young)
- `z80-beeper` — 1-bit beeper engine source code (utz82)
- `z80-library` — Z80 library routines (Dean Belfield)
- `z80-binary-analysis` — reverse engineering: disassembly, call graphs, sound signatures
- `z80-demoscene` — demoscene techniques: size coding, hardware timing, effects
- `z80-tutorial` — learning Z80: registers, addressing, first programs, debugging
- `spectrum-rom` — ROM entry points and routines
- `spectrum-hardware` — ULA, display file, system variables, I/O ports
- `wasm-spec` — WASM instruction set, WAT text format, MDN pages
- `wasm-binary` — WASM binary format (values, types, modules)
- `wasm-pattern` — common WASM/WAT code patterns
- `wasi` — WASI preview1 host function signatures
- `ml-regression` — linear/logistic regression: difficulty curves, damage scaling, projectile prediction
- `ml-trees` — decision trees + random forests: enemy behaviour trees, state-based AI
- `ml-boosting` — gradient boosting, AdaBoost: ensemble enemy AI, combining weak heuristics
- `ml-svm` — support vector machines: classifying player style, boundary decisions
- `ml-clustering` — k-means, hierarchical: grouping game states, enemy formation patterns
- `ml-dimensionality` — PCA, feature selection: state compression for extreme-edge (48KB)
- `ml-distillation` — model distillation to lookup tables: training in Python, deploying as Z80 branch tables
- `ml-pattern` — cross-cutting ML patterns: train/test, overfitting, bias-variance, evaluation — game examples
