## Project Plan: Stage 3 Chroma -  Harmonic Transmedia Loop (HTL)

A human-in-the-loop creative pipeline that translates visual composition into structured musical JSON, allowing artists to remix structural metadata and drive cross-modal generative evolution.

### Technical & Architectural Progression

#### 1. Visual Extraction & Physical Mapping (Image → JSON Seed)
* **Image Analysis:** A visual-language model scans an initial image to extract spatial geometry, lighting, color spectrum, and focal objects.
* **Structural Translation:** Visual features are reverse-engineered into readable musical and physical execution data:
  * Topography & Lines → Melodic contours (stepwise motion vs. wide leaping pitches)
  * Object Density & Chaos → Biomechanical difficulty bounds (`target_level`, `finger_speed`, `rhythmic_grid`)
  * Object Frequency → Pitch repetition counts
  * Scale & Depth → Tempo, voice polyphony, and rest durations (negative space)
  * Atmosphere & Lighting → Key signatures, harmonic modes, and initial metadata

#### 2. Human-in-the-Loop Remix (Metadata, Playability & Note Editing)
* **Modular Control:** The user accesses the intermediate JSON code block as a tactile control panel.
* **Parameter Adjustment:** The artist manually tweaks structural and physical DNA:
  * Modifying high-level metadata (`style`, `mood`, `character`)
  * Adjusting playability constraints (`target_level`, `max_hand_span`, `hand_independence`) to instantly downscale a complex visual seed into an accessible beginner piano arrangement
  * Transposing note registers or adjusting tempo (`BPM`)
  * Editing beat values and voice polyphony while retaining the underlying melodic motif

#### 3. Cross-Modal Synthesis (JSON → New Media)
* **Audio & Performance Rendering:** The modified JSON is compiled into playable MIDI (enforcing finger mechanics) or synthesized audio tracks via DSP.
* **Generative Descendants:** The updated JSON is fed back into a generative image engine. Physical execution friction (high finger speed, tight leaps) translates into visual turbulence and pulse speed, producing a new visual evolution that inherits the exact harmonic and physical bones of the original seed image while adopting a completely new aesthetic.
